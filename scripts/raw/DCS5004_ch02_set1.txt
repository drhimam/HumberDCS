Answer Key with Short Explanations
1. C: Factor = new ÷ original = 20 ÷ 5 = 4.
2. B: 18 ÷ 6 = 3, so it decreased by a factor of 3.
3. A: d = ct; with c constant, distance is directly proportional to time.
4. B: In y = kx, halving x halves y.
5. C: With c constant, c = fλ, so doubling f halves λ.
6. C: Quartering f makes λ four times longer.
7. A: T = 1/f = 1 ÷ (5 × 10⁶ Hz) = 0.2 µs.
8. B: f = 1/T = 1 ÷ (0.5 × 10⁻⁶ s) = 2 MHz.
9. C: Frequency and period satisfy f = 1/T.
10. C: Halving the frequency doubles the reciprocal period.
11. B: Inverse: halving one variable doubles the other.
12. D: Inverse: multiplying one by 5 multiplies the other by 1/5.
13. D: Depth changes by 8 ÷ 2 = 4, so return time changes by the same factor.
14. D: Depth falls to one-third, so return time falls to one-third.
15. A: c = fλ gives an inverse relationship only for constant speed (same medium).
16. C: I = P/A; intensity tracks power directly only when area is constant.
17. C: Divide both sides of c = d/t appropriately: t = d/c.
18. B: Divide both sides of c = fλ by f: λ = c/f.
19. D: Invert f = 1/T: T = 1/f.
20. B: Multiply by A, divide by I: A = P/I.
21. A: Speed is distance per time (m/s).
22. C: Frequency is measured in hertz.
23. B: Period is a time, in seconds.
24. C: Intensity is power per unit area (W/cm²).
25. D: (m/s) × s = m.

27. B: λ = c/f = 1540 ÷ (2 × 10⁶) = 0.00077 m = 0.77 mm.
